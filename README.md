# Kickstarter Landing Page

## 📌 Description
This project is a fully responsive landing page built based on a Figma design.
It includes multiple sections such as header, features, testimonials, and more, with smooth animations and a well-structured layout.

The main goal of this project was to strengthen skills in semantic HTML, SCSS, BEM methodology, and responsive web design.

## 🛠 Technologies Used
- HTML5
- SCSS (Sass)
- BEM methodology
- JavaScript (ES6)
- Flexbox & CSS Grid
- Responsive design
- Animations (WOW.js, Animate.css)
- Git & GitHub

## 🚀 How to Run the Project Locally

1. Clone the repository:
```bash
git clone https://github.com/mariiamad/Kickstarter.git
```

2. Go to the project folder:
```bash
cd Kickstarter
```

3. Install dependencies:
```bash
npm install
```

4. Run the project:
```bash
npm start
```

## ⚡ Challenges & Solutions

### 🔹 Responsive Layout
**Challenge:** Adapting complex design across multiple breakpoints (1440px, 1280px, 640px, mobile).
**Solution:** Used a combination of Flexbox and CSS Grid, along with media queries to ensure smooth transitions between screen sizes.

### 🔹 BEM Structure
**Challenge:** Keeping styles scalable and maintainable in a large layout.
**Solution:** Applied BEM methodology to organize components clearly and avoid style conflicts.

### 🔹 Animations on Scroll
**Challenge:** Implementing smooth and performant animations without affecting user experience.
**Solution:** Integrated WOW.js with Animate.css and optimized animation triggers.

### 🔹 Cross-browser Compatibility
**Challenge:** Ensuring consistent appearance across different browsers.
**Solution:** Tested layout in multiple browsers and adjusted styles where necessary.

### 🔹 Code Maintainability
**Challenge:** Managing a growing codebase with many sections.
**Solution:** Split styles into SCSS partials and kept components modular and reusable.
