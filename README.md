# CrazyBaby Landing Page

A responsive landing page for CrazyBaby, built according to the provided
Figma design.

The website presents the CrazyBaby wireless speaker, its benefits, technology,
features, customer testimonials, and a contact form. It is fully responsive
and adapted for mobile, tablet, and desktop screens.

## Live Demo

[View the live website](https://anastasiia-rem.github.io/Kickstarter/)

## Design

[Figma design](https://www.figma.com/design/Ujp7bCFuvuJlkn8TSbQPSZ/Kickstarter_FE-students?node-id=24223-3659&t=PgOAdYezEcLhPWKq-0)

## Technologies Used

- HTML5
- SCSS
- BEM methodology
- JavaScript
- Responsive Web Design
- CSS Grid
- Flexbox

## Features

- Responsive layout for mobile, tablet, and desktop
- Hamburger navigation menu
- Smooth scrolling between page sections
- Interactive benefits and features sliders
- Contact form with validation
- Hover effects and scroll animations
- Interactive social media links

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Anastasiia-Rem/Kickstarter.git
   ```

2. Go to the project directory:

   ```bash
   cd Kickstarter
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
